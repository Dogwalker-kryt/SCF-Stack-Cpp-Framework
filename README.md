# SCF-Stack-Cpp-Framework
SCF is a stack memory focused C++ 17 Framework that is (will be in the future) able to replace the Std STL 

## Description

This Framework (SCF) is a Stack memory C++17 Framework. It provides diffrent functionality for varoius functions (as the features part shows) that work only with/on Stack memory

---

## Featrues

**Every functions and type is under the ```scf::``` namespace!**

### IO

scf::print()
scf::println()
scf::read()

### Data Types

#### Strings

scf::str8
scf::str16
scf::str32
scf::str64
scf::str128
scf::str256
scf::str512

These are string types that only allocate on the stack and dont use any heap memory.
They have **almost** all functionality that the STL strings have
they can work with the STL strings.

#### Arrays

scf::array<Type, size>
